# 👨‍💼 Burger Bills - Staff Operations Guide

## Staff Panel Access

### **How to Login**
1. Go to: `http://your-site.com/staff/login/`
2. Enter your **staff username** and **password**
3. Click **"Login"**
4. You'll see the **Staff Panel**

---

## 📊 Staff Panel Overview

The staff panel has several sections:

| Section | Purpose |
|---------|---------|
| **All Orders** | View ALL orders from all tables |
| **Kitchen View** | Prep area - see orders to cook |
| **Ready Orders** | Orders finished, waiting for customer |
| **Staff Settings** | Account management |

---

## 🍳 Kitchen Workflow - Making Food

### **Step 1: View New Orders** 
- Go to **"Kitchen View"** or **"All Orders"**
- See list of **pending orders** (newest first)
- Each order shows:
  - 📋 Order number
  - 🪑 Table number
  - 📝 Items to cook
  - ⏱️ Time ordered

### **Step 2: Start Cooking**
- Read the **special requests** for each item
- Cook according to specifications:
  - "No onions" = Don't add onions
  - "Extra cheese" = Add extra
  - "Well done" = Cook longer
- Work efficiently!

### **Step 3: Mark as Ready**
- When order is complete, click **"Mark as Ready"**
- **Order status changes to: READY**
- Customer will see their order is ready
- Kitchen display updates automatically

### **Step 4: Order Complete**
- After customer receives food, staff marks as **"Complete"**
- Order moves out of active list
- Can be viewed in **"Reports"** section for records

---

## 📞 Calling Customers

### **When Order is Ready**

1. Look in **"Ready Orders"** section
2. Find the customer's **table number**
3. **Call out their table number** loudly:
   - "Table 5, your order is ready!"
   - "Order for Table 5!"

4. Click **"Call Customer"** button (optional)
   - This records that you notified them
   - Useful for tracking response time

5. **Serve the food** to the table
6. Mark as **"Complete"**

---

## 📋 Order Status Flow

```
PENDING (New order from customer)
   ↓
CONFIRMED (Order received by staff)
   ↓
PREPARING (Cooking in progress)
   ↓
READY (Food is done, ready to serve)
   ↓
COMPLETED (Customer has received food)
```

## 🔍 Finding Specific Orders

### **Method 1: Browse All Orders**
- Go to **"All Orders"**
- See all orders on the screen
- Orders show table numbers clearly

### **Method 2: Search by Table**
- If a customer asks about their order
- Look for their **table number** in the list
- Check the **status**

### **Method 3: Check Pending Only**
- See just **new/pending orders** that need cooking
- Fastest way to see what needs to be made

## ⏱️ Tracking Order Times

Each order shows:
- **Time ordered** - when customer placed the order
- **Estimated time** - expected ready time (usually 20 min)
- **Actual time** - how long it took

**If an order is taking too long:**
1. Check if there are special requests
2. Prioritize based on customer wait time
3. Communicate with kitchen team

## 🆘 Troubleshooting

### **Problem: Order doesn't update**
- **Solution:** Refresh the page (F5)
- System syncs automatically but refresh helps

### **Problem: Can't see a table's orders**
- **Solution:** 
  - Check if table number is correct
  - Try "All Orders" view
  - Ask the customer for their table number

### **Problem: Customer says they didn't receive order**
- **Solution:**
  - Check order status in system
  - Look at when it was marked ready
  - Review who called/served it

### **Problem: Forgot password**
- **Solution:** 
  - Contact manager for password reset
  - Don't write passwords down!

---

## 💡 Best Practices

✅ **DO:**
- Check orders regularly (every 2-3 minutes)
- Call customers promptly when ready
- Read special requests carefully
- Keep kitchen view visible during rush
- Mark orders as complete after serving

❌ **DON'T:**
- Leave pending orders unread
- Forget to call customers
- Ignore special requests
- Close browser without logout
- Share login credentials
